## Documentation Operating Rule

GitHub is the canonical documentation source. GitBook may publish and present these Markdown files, but durable operating knowledge, release evidence, deployment records, architecture decisions, and closeouts must be committed to this repository.

A production work item is not fully closed until its release documentation is recorded here.
