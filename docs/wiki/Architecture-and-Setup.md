# Architecture and Setup

The repository combines:
- Markdown / Obsidian vault content and metadata contracts;
- Next.js web application and executive dashboard;
- Bases-first and Dataview-assisted navigation;
- React Flow / drag-drop visual operations;
- governed draft-PR write workflows;
- optional browser voice capabilities;
- agent-operation documentation for coding/project agents.

Canonical operational docs include the owner manual, MAPS, metadata schema, deployment guide, release notes, web-vault portal architecture, and web-agent operations guide.
